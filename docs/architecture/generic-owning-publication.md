# Saved generic catalog ownership

The generic opt-in is an explicit saved biome-source policy; an absent field remains legacy. Version 1 saves cellular-v1, spacing in WORLD BLOCKS and a sorted unique possible-biome pool. The initial pack pool has 116 IDs. Source decoding resolves every holder early and verifies the fallback and cave routes before possibleBiomes or feature sorting. Generic possibleBiomes follows ASCII pool order; the legacy initializer and encounter order are preserved. A partial Terralith cave pool is invalid. Future provider presets can omit Terralith routes when their supported pool and compatibility routes do not require them.

At normal Overworld load, saved scale initializes first. The platform factory verifies codec holders against the owning registry, then binds seed, scale, policy and palette to the registry controller before provider initialization. Catalog reload can precede this binding. Invalid initial pool membership yields an inactive owning classification with metadata diagnostics. Later out-of-pool proposals reject the complete replacement and retain the prior metadata/activation/world publication. Exact reload-wrapper identity and aggregate-success activation remain unchanged.

The controller publishes one immutable record containing catalog, activation, revision and owning handles. Its private parser state is never exposed to runtime reads. Provider enqueue captures a complete owning publication once, before submission. Generic tiles retain integer indexes and that publication's palette object; legacy tiles retain shorts. Source decode requires its exact palette object and never substitutes plains for a broken generic encoding. Catalog reload does not invalidate cached or pending tiles or change possibleBiomes.

BiomeClassifier shares the accepted float derivation, smooth elevation, wet mask and snow equations. Generic land/ocean selection uses the compiled selector and one tile-confined primitive context. Transitional river binding is limited to the existing warm-river rule; generic paths do not consult process-global TerralithCompat. Inactive generic classification uses the existing compatible fallback routes through its owning integer palette. Actual #7 records add palette index/hash, saved spacing and the selector's actual site/tier decision without retaining holders. The trace quotas remain unchanged.

Generic seed and scale checks run before Explorer/SavedData mutation, and Explorer rechecks on the inference executor. Legacy checks are no-ops to preserve accepted live-provider behavior and scale 1 through 6. This does not fix the global coordinate cache keys or process-wide provider architecture. Generic source binding validates bounded canonical scratch before inference. Internal canonical tiles may spill at the ±30,000,000 border by tileSize−1, preserving all valid-column geometry and the fixed scratch site budget.

CPU gates compare every legacy ID and snow byte with the accepted #7 classifier at scales 1, 2 and 6, compare captured raw bits of all 34 fields, verify active/inactive generic output and transitional rivers, and exercise an arbitrary provider ID. Registry/codec feature sorting, normal enqueue capture, held pending work across reload, saved world reopening, raw native invariants and human representative maps remain actual runtime gates. Pure tests do not claim those results.
